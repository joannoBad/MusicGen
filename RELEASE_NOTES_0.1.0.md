# MusicGen 0.1.0

Первая публичная версия MusicGen.

## Что внутри

- Веб-версия генератора паролей из аудио
- Desktop-версия, работающая полностью офлайн
- Portable-сборка для Windows
- Поддержка `WAV` и `MP3`
- Два режима генерации: `Exact` и `Robust`
- Прослушивание загруженного аудио
- Неоновый интерфейс и музыкальная визуализация во время воспроизведения
- Лимиты на размер и длительность аудио
- Обрезка слишком длинного аудио перед анализом

## Важно

MusicGen не предназначен для критически важных секретов и не заменяет полноценный менеджер паролей.

Если использовать тот же самый аудиофрагмент и тот же режим генерации, можно получить тот же самый пароль.
